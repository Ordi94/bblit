# Formato: `0xDIRECCION Nombre  # origen: ...` (una por linea; las lineas vacias y las que empiezan por # se ignoran).
# `python -m tools.ghidra simbolos` lo lee y aplica el nombre a la funcion que empieza en esa direccion. Los
# nombres oficiales del SDK por firma tienen prioridad: si una direccion del archivo ya tiene nombre oficial no se
# cambia y el comando informa del choque. Un nombre repetido o igual al de otro simbolo tambien se informa y no se
# aplica. Nunca se edita config/symbols.txt a mano: se cambia este archivo y se regenera la tabla.

# excluyen tres nombres dudosos (CondTpnmv, CondTpmov, GsSetProjection) hasta comprobarlos.
